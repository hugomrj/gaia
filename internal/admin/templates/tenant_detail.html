Ejemplo de Uso

Copiá y pegá este código para hacer tu primera petición. Podés cambiar el mensaje de ejemplo por lo que necesites.

cURL

curl -X POST http://localhost:8080/v1/{{ .tenant.Slug }}/analyze \ -H "Authorization: Bearer {{ .tenant.TokenPlain }}" \ -H "Content-Type: application/json" \ # Opcional: especificá el proveedor si tenés más de uno activo -H "X-Provider: mistral" \ # Opcional: forzar un modelo específico (default: open-mistral-nemo) -H "X-Model: mistral-large-latest" \ -d '{"message": "cuanto facture hoy"}'

JavaScript (Fetch)

fetch("http://localhost:8080/v1/{{ .tenant.Slug }}/analyze", { method: "POST", headers: { "Authorization": "Bearer {{ .tenant.TokenPlain }}", "Content-Type": "application/json", "X-Provider": "mistral", // Opcional "X-Model": "mistral-large-latest" // Opcional }, body: JSON.stringify({ message: "cuanto facture hoy" }) }) .then(res => res.json()) .then(data => console.log(data));
⚠️ Importante: No compartas este token en lugares públicos. Si se filtra, pedile al administrador que lo rote.
